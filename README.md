### Доминик

С 1989 по 1994 год Школа бизнеса Бута Чикагского университета и ныне несуществующая компания Dominick’s Finer Foods заключили партнерство для проведения исследований на уровне магазинов в области управления полками и ценообразования. Вместе они провели рандомизированные эксперименты в более чем 25 различных категориях во всех магазинах этой сети из 100 магазинов. В результате этого исследовательского сотрудничества на этом ресурсе доступны данные о продажах более 3500 UPC на уровне магазинов примерно за девять лет.

Эти данные предназначены только для академических исследовательских целей. Пользователи должны упоминать в своих рабочих документах и/или публикациях Центр маркетинга Килтс при Школе бизнеса Бут Чикагского университета.

### Описание

Набор данных Доминика охватывает данные сканеров на уровне магазинов, собранные в Dominick’s Finer Foods за период более семи лет. Набор данных содержит два типа файлов: файлы конкретной категории и общие файлы. Общие файлы содержат информацию, относящуюся ко всем категориям проекта.
